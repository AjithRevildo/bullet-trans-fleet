# Bullet Trans Fleet Command Center

This repo now contains the initial monorepo foundation for the fleet platform. The project is intentionally structured so it can scale from a small fleet to large enterprise operations.

## Included foundation

- Monorepo workspace structure
- Backend API app with Express + TypeScript
- Frontend web app with React + Vite + TypeScript
- Shared package for cross-app types
- Root Docker Compose configuration
- Environment template and documentation entry point

## Next phase

The next step is to implement the actual fleet domain modules, authentication, database models, GPS engine, and real-time map functionality.
